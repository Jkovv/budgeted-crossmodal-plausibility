# Budgeted cross-modal plausibility checks for clinical trial data

Work in progress. At a fixed query budget (queries per patient per visit), do
cross-modal plausibility models catch more data errors than EDC-style range
rules? Built on the MIMIC-IV Clinical Database Demo, resampled to a clinical
trial visit schedule.

The literature check is in `docs/literature_check.md` and the pre-specified
analysis plan in `docs/analysis_plan.md`.
